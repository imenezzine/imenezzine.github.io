Avec Benjamin Georgeault, nous partageons notre retour d'expérience sur le découpage d'un monolithe Symfony en plusieurs applications avec API Platform :

- pourquoi API Platform complète si bien Symfony pour une architecture distribuée ;
- comment les State Providers et State Processors nous ont permis de manipuler les données ;
- nos solutions pour garder des composants propres et génériques dans une équipe de 15 développeurs et développeuses.

Un talk pour les équipes qui font face à des enjeux de passage à l'échelle, que ce soit sur un nouveau projet ou pour une migration.
