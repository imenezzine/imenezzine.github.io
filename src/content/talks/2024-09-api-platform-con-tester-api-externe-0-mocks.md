Comment tester une application Symfony qui dépend d'API externes, sans écrire de mocks ? Dans ce talk, je présente PHP-VCR, un outil qui enregistre les requêtes et réponses HTTP pour les rejouer lors des tests suivants : configuration, formats de stockage, modes d'enregistrement et hooks.

Pour aller plus loin : mon article [Utilisation de PHP-VCR pour enregistrer et rejouer les appels d'API en PHP](/articles/utilisation-de-php-vcr-pour-enregistrer-et-rejouer-les-appels-d-api-en-php).
